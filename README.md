🛠 Installation

📥 Clone Repository

git clone https://github.com/OWNERSYSTUMM/Ticgame.git

📂 Open Folder

cd Ticgame

📦 Install Requirements

pip install -r requirements.txt


---

⚙ Configuration

Create .env file and add:

BOT_TOKEN=your_bot_token
OWNER_ID=your_id


---

▶ Run The Bot

python bot.py

Play directly using inline buttons
